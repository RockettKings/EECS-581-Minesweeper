Estimation method - We estimated effort using story points, assigned during spring planning through 
team estimation. Each task on our GitHub project board was sized on a modified Fubonacci scale (1,2,3,5,8),
where the numbers reflect relative effor and complexity. The group that owned each task set its points. We chose
story points over direct hour estimates because relative sizing made more sense for a team without prior velocity
data. So Judging a task by it complexity allows the team to break it up into smaller task if necessary. 

Converting points to hours - To produce an hour estimate for planning, we mapped story points to hours with 
the conversion rate being 1.5 hours per point.
